# FIXES.md

## Problem Summary (Prior Session — Mobile Overflow Fixes)

On mobile devices (360–430px viewport), several sections were getting **visually cut off** on the right (and in one case the left) side. The root cause is hard-coded fixed Tailwind widths (`w-100`, `w-120`, `w-150`, `w-200`) that are wider than the viewport. When browsers clip overflow — which they do by default on deployed environments like Vercel — those elements get chopped.

---

## Changes Made (Prior Session)

### 1. `app/page.tsx`
Added `overflow-x-hidden w-full` to `<main>` as a global guard so no child element can break out of the viewport horizontally.

### 2. `components/containers/heroSection/heroSection.tsx`
- **Problem 1:** "Contact Me" button had `w-150` (600px) — overflows any mobile screen.
- **Fix:** Changed to `w-full max-w-150`.
- **Problem 2:** "FRONTEND DEVELOPER" gold text and its outline layer were `text-[120px]` on mobile — at that size "FRONTEND" alone is ~600px wide, far exceeding any mobile viewport.
- **Fix:** Changed both to `text-[80px] lg:text-[200px]`.

### 3. `components/containers/moreThanSection/moreThanSection.tsx`
- **Problem:** Both "With Me" and "Another Talent" comparison cards had `w-100` (400px) — wider than most mobile screens.
- **Fix:** Changed both to `w-full max-w-100 lg:max-w-150`.

### 4. `components/containers/designAccuracySection/designAccuracySection.tsx`
- **Problem 1:** "See All" button had `w-100` (400px) — overflows mobile.
- **Fix:** Changed to `w-full max-w-100`.
- **Problem 2:** All 3 portfolio image cards had `w-100` (400px) — overflows mobile.
- **Fix:** Changed all to `w-full max-w-100`.
- **Problem 3:** The badge sticker used `absolute -left-8` (−32px), causing it to clip off the **left** edge of the screen on mobile.
- **Fix:** Added `pl-12` to the card row container on mobile (`lg:pl-5` restores the original on desktop) to give the badge enough room.
- **Problem 4:** "See All" button was pushed to the right edge of the screen. The header row had `lg:justify-between` without `w-full`, and the text div had `lg:w-250` (1000px) — forcing the row to ~1300px wide, overflowing most viewports. On mobile, `items-center` was only applied at `lg:`, so the button was not centered.
- **Fix:** Added `w-full` to the header row, moved `items-center` off the `lg:` prefix (applies on all breakpoints), removed `lg:w-250` from the text div and `lg:w-230` from the paragraph, reduced `gap-25` to `gap-10`.

### 5. `components/containers/testimoni/testimoni.tsx`
- **Problem:** Outer container had `w-120` (480px) on mobile — overflows.
- **Fix:** Changed to `w-full` (already `lg:w-full` on desktop, now consistent on mobile too).

### 6. `components/containers/workSection/workSection.tsx`
- **Problem:** Portfolio preview image had `w-200` (800px) — the **worst offender**, more than double the mobile viewport.
- **Fix:** Changed to `w-full max-w-200`.

### 7. `components/containers/form/form.tsx`
- **Problem:** The contact Card had `w-100` (400px) — overflows on small screens.
- **Fix:** Changed to `w-full max-w-100`.

### 8. `components/containers/codeDesignSection/codeDesignSection.tsx`
- **Problem:** Two pill cards side-by-side (`w-45` each) = ~380px + gap, which fails on 360px screens.
- **Fix:** Added `flex-wrap` to the pill row so they stack on very narrow screens.

---

## Pattern Applied (Prior Session)

Every fix follows the same rule:

```
w-[fixed]  →  w-full max-w-[fixed]
```

This makes elements fill available width on mobile while capping at the intended design size on larger screens. No layout or visual design was changed on desktop.
