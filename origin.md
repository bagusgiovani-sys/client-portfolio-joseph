## Critical Findings (must-fix)

1. **[QUAL] Placeholder site metadata** — `app/layout.tsx:26-29`: title is "Create Next App" and description is "Generated by create next app". This is the first thing search engines and social previews show — catastrophic for a job-seeking portfolio.
2. **[QUAL] FAQ placeholder content** — `components/containers/accordion/accordion.tsx:21-40`: Items `remote`, `figma`, `backend`, and `fulltime` all show "View your current plan, payment history..." — generic shadcn placeholder text that was never replaced.
3. **[QUAL] Non-functional interactive elements** — Multiple buttons/links exist in the UI but do nothing: Hero "Contact Me" (`heroSection.tsx:109`), Projects "See All" (`designAccuracySection.tsx:18`), footer social icon `<div>` wrappers (`footer.tsx` — all four social icons are unclickable divs, not `<a>` tags).

## Major Findings (should-fix)

4. **[PERF] Raw `<img>` everywhere** — Every component uses HTML `<img>` instead of Next.js `<Image>`. Missing: automatic lazy loading, size optimization, WebP conversion, CLS prevention. Affects all 13 section components and footer.
5. **[QUAL] Dead `showModal` state** — `components/containers/form/form.tsx:17`: `const [showModal, setShowModal] = useState(false)` is declared but never read. Only `modalType` drives modal visibility. Dead code.
6. **[QUAL] Non-functional carousel arrows** — `codeDesignSection.tsx:65-67` and `testimoni.tsx:50-52`: Arrow buttons rendered with no click handlers. The shadcn Carousel component (`components/ui/carousel.tsx`) is available but never used in these sections.
7. **[DX] PascalCase violations on component function names** — `heroSection`, `asFrontendSection`, `codeDesignSection`, `moreThanSection`, `designAccuracySection`, `experienceSection`, `clearSection`, `testimoni`, `workSection` all export lowercase function names. React convention requires PascalCase for component functions.
8. **[QUAL] Unnecessary `"use client"` on clearSection** — `clearSection.tsx:1`: The component doesn't use hooks or browser APIs directly; it just renders `<AccordionSection>` which is already a client component. The directive is redundant in App Router.

## Minor Findings (nice-to-fix)

9. **[QUAL] Duplicate CSS rules** — `globals.css:139-145`: `@apply border-border outline-ring/50` and `@apply bg-background text-foreground` are each written twice in the same CSS block.
10. **[QUAL] Duplicate `scroll-behavior: smooth`** — `globals.css:11` and `globals.css:149-152`: defined at root level AND inside `@layer base { html }`.
11. **[QUAL] Wrong alt text on portfolio images** — `designAccuracySection.tsx:63,88`: both portfolio2 and portfolio3 images have `alt="portofolio1"`.
12. **[DX] Generic package name** — `package.json:2`: name is `"my-app"`.
13. **[QUAL] Dark mode tokens defined but never used** — `globals.css:103-135`: Full dark theme CSS variable set is present but there is no dark mode toggle anywhere in the UI.
14. **[CHORE] Sidebar tokens are unused boilerplate** — `globals.css`: All `--sidebar-*` variables are shadcn init boilerplate; no sidebar component exists in the project.
